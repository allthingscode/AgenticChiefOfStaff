# Tool Usage Notes

## `exec`

The `exec` tool runs shell commands.

### Safety Limits

- **Timeout**: Configurable (default 60s).
- **Blocked**: Dangerous commands are blocked.
- **Truncation**: Output is truncated at 10,000 characters.
- **File Access**: Can be restricted to workspace.
